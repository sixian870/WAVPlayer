# WAV音效檔播放器

透過簡潔直觀的使用者介面，除了提供 WAV 音效檔案的讀取、播放、循環聆聽與暫停功能，還支援將未壓縮的 WAV 檔案一鍵轉換為 MP3、AAC、WMA 及無損 FLAC 等音樂格式的轉檔功能。


## 核心功能

### 1. 基礎音效播放控制

* **音效載入與播放**：透過檔案對話方塊篩選並載入 WAV 檔案進行播放。
  
* **循環播放機制**：支援音效循環播放，適合用於背景音樂或重複性音效測試。
  
* **即時中斷控制**：提供獨立的停止按鈕，可隨時中斷正在進行的音訊輸出。

### 2. 多格式音訊轉檔

整合 NAudio 與 NReco.VideoConverter 提供四種轉檔選擇：

* **MP3**：高相容性的普及有損格式。

* **AAC (.m4a)**：高音質有損壓縮，蘋果生態系愛用。

* **WMA**：微軟原生的 Windows Media Audio 格式。

* **FLAC**：無損音訊壓縮格式，縮小檔案同時保留 100% 音質。

### 3. 防呆與保護機制

* **資料與路徑驗證**：在執行「播放」或「轉檔」前，系統會自動檢查路徑是否為空、檔案是否存在，以及副檔名是否為 .wav，若有誤將彈出警告視窗攔截。
  
* **防檔案鎖定衝突**：在執行轉檔作業前，系統會自動停止當前正在播放的音效，確保檔案資源被釋放，避免「檔案被其他程序佔用」的崩潰錯誤。

* **防誤觸關閉設計**：無論是點擊結束按鈕還是視窗右上角的「X」，都會彈出確認對話方塊，防止使用者意外遺失工作進度。

### 4. 友善的使用者體驗

* **轉檔狀態提示**：在進行較耗時的轉檔作業時，視窗標題會動態切換為「轉檔中請稍候...」，並強制刷新畫面，防止使用者誤以為程式當機。

* **轉檔成功回報**：轉檔完成後，會明確彈出提示視窗，並附上轉檔後的完整儲存路徑，方便使用者尋找檔案。

2.  **功能選擇**：
    * **僅播放一次音效**：點擊 `播放一次` 按鈕，系統將從頭播放該 WAV 檔一次，若發生錯誤將跳出視窗提醒。

    * **重複播放音效**：點擊 `重複播放` 按鈕，音效將不斷循環直到手動停止，若發生錯誤將跳出視窗提醒。

    * **停止播放音效**：點擊 `停止播放` 按鈕，立刻中斷當前所有的音效輸出。

    * **轉換音效檔案格式**：點擊 `轉換格式` 按鈕，若發生錯誤將跳出視窗提醒。
      * 系統將彈出儲存對話方塊，供使用者選擇轉檔後檔案儲存位置。
      * 預設檔名會自動帶入原 WAV 檔的名稱，使用者可自行修改。
